# 分手大师 — Beta

**《分手大师》**不是只处理分手，而是一套双语 Relationship Intelligence Skill：覆盖暧昧、situationship、要不要开始交往、要不要继续/升级关系、关系危机、背叛、分手、复合和走出来。

它不会默认劝你“放下”，也不会默认帮你“追回来”。它先查事实、还原时间线、分别建立双方模型，再结合文化、地域、家庭系统、LGBTQ+ 情境、人生阶段和现实条件，区分这段关系到底值不值得、难不难、现实上能不能成立。存在多个合理解释时，用概率和置信度表达，不为了完整而硬猜。

心理学部分采用多框架：依恋研究、EFT、Gottman 关系研究、Bowen 家庭系统、情绪调节、社会拒绝与社会痛苦、哀伤、自我同情、边界、欲望与承诺等。需要深度解释时，应自然说明所使用的理论、心理学家或书籍，并区分实证研究、临床框架和大众心理学。

## 在 Codex 里怎么用

安装 Skill 后，直接告诉 Codex 使用 `breakup-master` 即可，不需要记特殊命令。

例如：

```text
用 breakup-master 分析我这段关系。
```

```text
用 breakup-master。我现在在暧昧，帮我判断这个人值不值得认真交往。
```

```text
用 breakup-master 判断这段关系值不值得复合。
```

```text
用 breakup-master，切 Brutal Reality Check 模式，不要安慰我。
```

```text
用 breakup-master，切 Move On 模式。
```

也可以直接自然地问，例如：

- “这个人值得开始交往吗？”
- “这段暧昧还值得继续吗？”
- “前任回来我该不该答应？”
- “我为什么放不下？”
- “分析一下我们现在的状态。”
- “我不要安慰，直接告诉我现实情况。”

如果 Skill 已经安装并可用，Codex 会按这套 Skill 的关系法证、心理学、本地化、概率和决策框架来处理。

## 语言

中文和英文都是一级语言。默认跟随用户主要语言，也支持 English only / 中文 / 双语。建议会根据用户实际国家、地区和文化环境本地化，而不是机械套用美国或中国的关系模板。

## 状态

**Public Beta。** 本 Skill 用于关系分析和决策支持，不替代心理治疗、医学诊断、紧急危机服务或法律代理。
