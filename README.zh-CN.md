# 分手大师 — Beta

一个面向 Codex 的双语、证据导向关系决策 Skill。

当前版本以 **Goal Lock（目标锁定）** 为核心：用户明确最终目标后，后续分析必须服务于这个目标，不能悄悄变成研究前任、提高联系频率或制造希望。

## 核心能力

- 先还原事实，再做心理解释
- 严格区分联系、好感、依恋、后悔、复合意图、复合准备度与持续承诺
- 主动识别目标漂移
- 防止把流畅的心理叙事误当成事实
- 用户高度激活时切换到简短稳定模式
- 根据联系对用户稳定性和最终目标的影响来选择联系策略
- 区分真正的边界与惩罚、刺激对方反应的控制实验
- 连续 case 只做增量更新，不因一条新消息重写整个故事
- 根据文化、地域、家庭结构、性取向和实际关系协议进行本地化分析

详细心理框架、证据协议与高风险处理流程放在 `references/` 中，仅在相关 case 中读取。

本 Skill 用于关系分析与决策支持，不替代临床诊断、心理治疗、紧急服务或法律代理。
