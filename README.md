# Breakup Master — Beta

A bilingual, evidence-led relationship decision-support skill for Codex.

The current version is built around **Goal Lock**: once a user states what they are trying to achieve, later analysis must serve that goal instead of quietly switching to monitoring an ex, maximizing contact, or manufacturing hope.

## Core behavior

- reconstruct facts before psychology
- separate contact, affection, attachment, regret, reconciliation intent, readiness and sustained commitment
- detect goal drift
- prevent confident mind-reading
- switch to a shorter stabilization mode when the user is highly activated
- evaluate contact by its effect on the user's stability and goal
- distinguish boundaries from attempts to punish or provoke a reaction
- update ongoing cases incrementally instead of rewriting the entire story
- localize culture, geography, family structure, sexuality and relationship agreements

Detailed frameworks and high-risk procedures live in `references/` and are loaded only when relevant.

This is relationship analysis and decision support, not diagnosis, psychotherapy, emergency care or legal representation.
